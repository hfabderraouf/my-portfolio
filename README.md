# Portfolio Website

A clean, responsive, and interactive personal portfolio showcasing my web development projects, technical skills, and experience.

## Features
- **Responsive Navigation**: Mobile-friendly sidebar menu with smooth toggle functionality.
- **3D Coverflow Gallery**: Interactive card carousel for showcasing featured projects.
- **Tab Navigation**: Clean interface for viewing personal background and details.
- **CSS Theme Options**: Distinct visual sections for clean content presentation.

## Tech Stack
- **HTML5** – Semantic structure
- **CSS3** – Custom styling, responsive layouts, and animations
- **JavaScript (ES6)** – DOM manipulation, event handling, and 3D coverflow logic
